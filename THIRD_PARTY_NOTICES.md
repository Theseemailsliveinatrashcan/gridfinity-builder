# Cullenect label system

Cullenect label system by Cullen J Webb (MIT); not affiliated.
Source standard: https://github.com/CullenJWebb/Cullenect-Labels#standards-and-dimensions---gridfinity

Socket geometry in this app is an independent implementation of the published V2 dimensions, not copied OpenSCAD code. V2 uses a 1.2 mm label, 11 mm height, width 42 mm × units − 6 mm, a 0.2 mm perimeter latch and 0.4 mm socket retention ribs. Our fit reference also models the optional 1U legacy rear grooves described by gflabel; no gflabel source code is included.
